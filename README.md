# أداة ريندر الفيديوهات — Abdo Elmasry × Ahmed Ben Ali

بتحوّل ملفات المعاينة (HTML) لفيديو **MP4 بجودة 1080×1920، فريم بفريم من غير تقطيع، وبالصوت**، من غير ما تستهلك أي كريديت من Claude.

## الطريقة الأولى: GitHub (من غير ما تسطب أي حاجة)
1. ارفع محتويات الفولدر ده على ريبو في جيتهاب (مرة واحدة بس).
2. كل ما تحب تطلّع فيديو: افتح ملف المعاينة، اختار الألوان، واضغط **«💾 حفظ ملف بالألوان دي»**.
3. ارفع الملف اللي نزل جوه فولدر **input** في الريبو (Add file ← Upload files).
4. روح تاب **Actions**، هتلاقي «Render videos» شغالة. بعد 5–10 دقايق افتحها، وتحت في **Artifacts** نزّل **videos** (فيها الـMP4).

## الطريقة التانية: على جهازك
محتاج مرة واحدة: [Node.js](https://nodejs.org) و [FFmpeg](https://ffmpeg.org/download.html).
```
npm install
npx playwright install chromium
npm run render
```
الفيديوهات بتطلع في فولدر **output**.

> الأداة بتطلّع فيديو لكل ملف `.html` موجود في فولدر input.
